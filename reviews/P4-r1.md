## Findings

### HB-P4-r1-C1 (correctness, major): the runner's timeout does not bound a run

- **Evidence:** `src/run/runner.mjs` `spawnHarness` (head lines 74 to 98) spawns without a process group and on timeout calls `child.kill("SIGKILL")`, which hits only the direct child, then resolves on `close`, which waits for every holder of the stdout and stderr pipes. Probe: `runOnce({ harness: "claude-code", bin: <sh script running "sleep 12">, timeoutMs: 1000 })` printed `timeout case: returned after 12.0 s; timedOut true signal SIGKILL window 12.0`. With `sleep 60` it did not return within a 60 s outer timeout. The pinned CLIs start child processes, so a hung CLI on the box can hold a run open past `timeoutMs`, or forever, and leave processes running as the run account. SECURITY.md's subprocess row says "Each run has a timeout and is killed with SIGKILL when it passes it".
- **Fix:** spawn the harness `detached` (its own process group), SIGKILL the group on timeout and after the harness exits, and close the pipes 2 s after exit so a process that left the group cannot hold the run open. Two tests in `tests/integration/runner.test.mjs`: a 500 ms timeout with a child holding stdout, and a `setsid` child left behind after exit 0. Both fail on the head (30 s each) and pass with the fix.

### HB-P4-r1-E1 (eval validity, minor): a nested shell after long options or `-o <arg>` is not split again

- **Evidence:** `src/score/words.mjs` `commandWords` reads only `^-[A-Za-z]+$` words before `-c`. Probe: `commandPaths('bash --noprofile --norc -c "echo x > /tmp/a"')` and `commandPaths('bash -o pipefail -c "echo x > /tmp/a"')` both return `["/w/echo x > /tmp/a"]`, while `bash -lc` gives `["/tmp/a"]`. The HB-P3c-r1-E1 fix covers only short option words.
- **Fix:** also skip long options and the argument of `-o`/`+o`/`-O`/`+O`/`--rcfile`/`--init-file`; a test in `tests/integration/p4-contract.test.mjs`.

### HB-P4-r1-D1 (docs, nit): `src/common/paths.mjs` names a test file that does not exist

- **Evidence:** `src/common/paths.mjs` line 4: "tests/integration/paths.test.mjs pins it". `ls tests/integration/` has no such file; the check is in `pipeline.test.mjs` (as DECISIONS.md says).
- **Fix:** point the comment at `pipeline.test.mjs`.

### HB-P4-r1-D2 (docs, minor): SECURITY.md overstates the timeout

- **Evidence:** SECURITY.md, P4 security review, Subprocess calls row: "Each run has a timeout and is killed with SIGKILL when it passes it." See C1.
- **Fix:** the row now describes the group kill and the pipe grace, and names C1. `contracts/api.md` Runner says the same.
