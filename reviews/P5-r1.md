## Findings

### HB-P5-r1-C1 (correctness, major): the box's fresh checkout has no project dependencies, so the eval dies at import

Evidence: forge run 45517382049, step "scripts/eval.sh in the project's sandbox profile":
`Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'derm-workspace' imported from .../project/src/model/server.mjs`, then `eval.sh exit 1`. `package.json` depends on `derm-workspace` (a git URL); forge's `eval.yml` runs no `npm` step and the sandbox network is 127.0.0.1 only; `scripts/p5-setup.sh` installed the CLIs and the monitor but not this repo's own dependencies. The PR body says the eval "stops with exit 3" at the rules preflight; it never got that far.

Fix: `p5-setup.sh` runs `npm ci --ignore-scripts` for this repo's `package.json`/`package-lock.json` into `<prefix>/deps`. `eval.sh`, when `node_modules/derm-workspace` is missing, links `node_modules` to `<prefix>/deps/node_modules` if the lockfiles are identical, and otherwise exits 3 naming `p5-setup.sh`. Tests: `tests/integration/p5-eval-sh.test.mjs` (stale lock refused, matching lock linked).

### HB-P5-r1-C2 (correctness, major): `eval.sh`'s column is `monitor`; forge runs this project as a landrun pass plus an `srt` column

Evidence: forge `queue.json` gives harness-bench `"columns_outside_landrun": ["srt"]`, and `sandbox/run-eval.sh` knows only `srt` ("forge knows how to run only: srt"). It runs the landrun pass with `FORGE_SKIP_COLUMNS=srt`, then `FORGE_COLUMN=srt`. Head `scripts/eval.sh` lines 25 to 32 skip only on `monitor` and exit 2 on any column other than `monitor`. So the landrun pass runs every stage under landrun, whose TCP rules allow the model port and 32768 to 60999 (this host's `ip_local_port_range`), not the collector's 4317/4318; and the srt column prints `eval: no column srt in this project` (same forge log) and exits 2 every time. No run of this head can set `forge/eval` green, whatever the audit rules.

Fix: the column is `srt`. The landrun pass with `srt` in `FORGE_SKIP_COLUMNS` writes a one-line `results/summary.md` and exits 0; `FORGE_COLUMN=srt` runs every stage with `HB_BOUNDARY=srt`; any other column exits 2. Tests in `tests/integration/p5-eval-sh.test.mjs`; all three fail on the round 1 `eval.sh` (0 / 3) and pass on round 2 (3 / 3).

Not verified here (needs the box): that the monitor's collector binds and the harnesses reach it inside `derm run --boundary srt`. The round 2 PR asks Tony to run the eval once after setup.

### HB-P5-r1-E1 (eval validity, minor): pilot rows name a commit that did not produce them

Evidence: `jq -r .git_sha results/p5-pilot.jsonl | sort | uniq -c` gives `216 6c5930130dc8...` (the P4 merge). `scripts/eval.mjs`, `src/monitor/beacon.mjs` and the startup widening that produced those rows do not exist at `6c59301`. `gitSha()` (`src/run/meta.mjs` line 31) is `git rev-parse HEAD` with no dirty check.

Fix: every row `eval.mjs` writes carries `worktree_clean` (false when a tracked file outside `results/` differs from HEAD). The failure case now states that the pilot rows came from the uncommitted P5 tree. Rows already written are not edited (contracts/results.md).

### HB-P5-r1-E2 (eval validity, minor): a second calibration appends to the startup list and widens it on every rerun

Evidence: `calibration()` (head `scripts/eval.mjs`, "append(file, rows)") appends to `results/startup-<h>-<v>.jsonl`, and `startupPaths` (`src/run/runner.mjs` line 62) reads every row in it. Two invocations in one checkout union two calibrations, so the repeat run the gate asks for would run on wider exclusions than the first. On the box each checkout is fresh, so this bites local and repeat-in-place runs only.

Fix: an existing non-empty startup list is reused as it stands, logged, and marked "reused, not recalibrated" in the summary; a new calibration needs a new `--startup-dir`.

### HB-P5-r1-D1 (docs, minor): the failure case quotes the wrong `audit_rules` label

Evidence: `results/P5-failure-case.md` line 3 says `host:derm_exec,derm_fork,derm_net,derm_write`; all 216 rows say `host:derm_exec,derm_fork,derm_net,derm_sens,derm_write`. Fix: quoted from the rows.
