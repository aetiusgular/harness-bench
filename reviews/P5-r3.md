### HB-P5-r3-E1 (eval validity, minor): a stage where every run is unanchored still exits 0

Evidence: `scripts/eval.mjs` `main()` (lines 255 to 267) writes the summary and returns 0 whatever `dropped` holds. `src/eval/aggregate.mjs` line 37 gives a null band when no repeat has a denominator. If the srt match fails on the box for every run (the case this session could not check), the eval would go green with null bands and a list of dropped runs. Nothing would be hidden, since the summary names every dropped run, but a green status would not mean the eval ran.
